# PRODUCT

本文件是产品总定义权威源，保存 Karl 已确认的产品存在性判断、产品定位、核心对象、最终成立状态、跨模块规则和模块索引。一个用户能力模块的一份 PRD 放在同目录，并由本文件维护入口；模块内尚未稳定的问题、候选方向与当前缺口保留在该 PRD 的当前交付区。

## 1. 产品存在性与用户现实

用户面对 Semrush 等复杂 Web 工具时，常常不知道页面功能的作用、参数应该怎样填写，以及操作后出现的结果意味着什么。文字回答需要用户自己映射回界面；预先写好的教程又无法随新的问题、操作和目标变化继续解释。

本产品让 Karl 在 Codex 中和 AI 一起看网页：在内置浏览器打开页面，通过对话提问，亲自操作，AI 重新观察变化并继续解释。需要指出具体对象时，由插件把高亮、箭头和必要的短提示画在真实页面上。用户可以只问懂一个选项，也可以在多轮讨论中逐渐完成一项任务。

## 2. 产品定义

- 产品名：`51-page-guide-agent`
- 一句话定义：让 Codex 在与你共同使用网页时，能够直接在页面上指给你看，并根据你的问题和操作结果持续调整帮助。
- 核心价值：解释准确对应眼前的页面，帮助随多轮对话和实际操作继续；用户在使用中理解工具并完成事情。
- 用户角色：当前阶段为 Karl 本人；面向所有需要使用复杂 Web 工具但不熟悉其界面的用户。
- 不做事项：独立插件侧栏、任务卡列表、教程播放器、知识卡阅读页或另一套内容预览界面；预置网站教程库；云端账号与多端同步；与页面指引无关的通用爬虫或数据提取。产品默认由用户操作网页，不因标注指令获得代点击、提交或业务写入授权。

## 3. 产品原则

- **对话是唯一使用入口**：提问、任务发现、深入学习、改变目标、继续和结束都在 Codex 对话里完成；用户无需先建立任务或选择教程。
- **插件没有独立操作界面**：插件是预先定义的标注工具和中间层，接收指令，定位、绘制、更新、撤下标注并返回结果。预先定义的是标注能力，具体标哪里、写什么由当前对话决定。
- **解释与知识留在对话**：完整说明、参数比较、Mermaid 图、图片和追问使用 Codex 当前可用的工具与展示能力；网页只保留对应具体对象的标注和必要短提示。工具的可用性按当前环境检查。
- **随操作重新观察**：AI 持续参与会话。页面跳转、用户改变选项或提出新问题后，重新观察，再决定下一次解释和标注，不依赖预先固定的步骤序列。
- **不限网站名单**：支持范围由当前浏览器实际可观察、可注入的页面决定，不以预置名单限制，也不承诺浏览器无法访问的页面。
- **现场验证与用户控制**：标注先核对页面和真实元素，定位失败就说明失败；用户亲自操作网页，随时可要求更新或清理标注。
- **本地保存服务于接续**：保存值得复用的说明、已验证定位和必要进展；重新使用时先检查当前页面。保存不是每次提问的前置条件，也不建立独立教程消费入口。
- **Skill 独立演进**：页面理解与任务指引方法沉淀为独立 Skill，不与某个模型或某个网站绑定。

## 4. 最终成立状态

Karl 在 Codex 内置浏览器中打开一个此前未配置过的复杂网页，直接在当前对话里提问。AI 观察页面，回答问题，必要时调用插件把解释指向真实元素。Karl 操作后，AI 根据新页面继续帮助；中途改换目标、比较两个选项或要求清理标记时，无需生成和重播完整教程。任务结束或中断后，有用的成果可在本地保留，下一次对话检查当前状态后接续。

产品由 Codex 对话与当前可用工具、内置浏览器、无独立界面的标注插件、必要的通信与本地保存能力组成。内置浏览器能否安装或运行现有 Chrome 扩展、怎样回传操作与标注结果，仍需验证；当前 Chrome 原型不能直接证明这一组合已经成立。

## 5. 核心对象

- **当前对话与网页**：用户提出问题、操作和获得帮助的中心；问题不必先成为完整任务。
- **页面标注**：对话中一次指示在真实元素上的呈现，可随新问题创建、替换和撤下。页面身份、目标定位、短提示与执行结果必须能对应当前网页。
- **本地复用资料**：按目标项目已有位置保留解释、定位和必要进展，帮助后续对话接续。旧 task.md、guide.json 与目录索引是现有原型格式，不决定新产品必须如何使用。

完整对象关系见模块 PRD：`01-product/page-guide-agent.md`。

## 6. 页面与交互规则

- 对话负责完整解释，网页标注负责让用户找到解释对应的对象；不在插件内复制一套内容阅读界面。
- 标注必须指向当前页面上的真实元素；无法确认时把失败返回对话，不错误指向。页面变化后更新或撤下旧标注。
- 用户的提问与实际操作决定接下来做什么，可以改变目标、顺序和解释深度；不把按钮点击或教程播放完毕视为任务成功。
- 用户随时可以通过对话要求标注、替换、清理或结束；网页原有操作仍然可用。
