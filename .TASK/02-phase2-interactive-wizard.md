<<<<<<<<<<<<<<<<<<<< 01A Objective Decomposition 目标对象定义 <<<<<<<<<<<<<<<<<<<<

- 目标对象：OpenRouter 模型页上的一个多步任务向导（≥4 步），含步骤状态机、完成判定、错误反馈、Lesson 知识卡。
- 结果维度：用户全程在页面上跟随指引操作，系统检测操作自动推进；做错如实反馈；想深入可展开知识卡。
- 排除项：AI 自动替用户操作；多端同步；真实网站改版自愈（另列）；付费外部服务。
- 交付形态：插件能力升级（content.js + sidepanel）+ 升级版任务文件（steps 带 completion 与 lesson）+ 端到端走查证据。
- 来源：PRD R10 / R11 / R16 与验收标准 6-7。

<<<<<<<<<<<<<<<<<<<< 01 PRD 目标和边界 <<<<<<<<<<<<<<<<<<<<

- 用户目标：按指引完成一个真实任务，系统识别每步操作并推进；出错有反馈；可展开知识卡深入阅读。
- 成功标准：PRD 验收标准 6、7 全部成立；R16 知识卡在 Side Panel 可展开阅读并经 Karl 确认有价值。
- 不做事项：见 01A 排除项。
- allowed files：`.project/02-tasks/`、`prototype/extension/`、`prototype/service/tasks/`、PRD 证据写回。
- Goal 关系：直接推进当前 active Goal 的 P2 三项证据。
- 验证预算：以真实页面端到端走查为主；不为状态机单独建自动化测试框架。
